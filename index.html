LinkShieldAI API Documentation

A refined, easy-to-navigate version of the published LinkShieldAI API documentation.

Authentication API key usage and access instructions. Endpoints Basic, detailed, screenshot, NSFW, and Chimera checks. Code Examples Published Python example for the basic endpoint.

Access

Authentication

To use the LinkShieldAI API, you need to obtain an API key. Include this key as a parameter in your requests.

To obtain an API key, join the LinkShieldAI Discord server.

Usage

Rate Limits

1000 daily requests
500 hourly requests
50 requests per minute

Exceeding these thresholds will trigger rate limit exceeded errors.

Basic Check

GET
URL
https://api.linkshieldai.com/?key={key}&url={url}

Endpoint

Chimera Endpoint

GET

The Chimera Endpoint is the gateway to LinkShieldAI's advanced artificial intelligence capabilities for website scanning. This endpoint uses AI models and signature detection to identify potential phishing, malware, and other malicious threats present in URLs.

URL
https://api.linkshieldai.com/chimera
Authentication
Requires an API key for access.
Description
Submit any URL to LinkShieldAI's analysis engine. The response provides a classification, a probability score, and the method used for detection.

Example Request

GET https://api.linkshieldai.com/chimera?key=YOUR_API_KEY_HERE&url=https://steamcomun1ty.com/id=5944478616

Successful Scan - Malicious URL

{
  "detection_method": "ai-model",
  "matched_signatures": 0,
  "probability": 0.9947241392537983,
  "result": "malicious",
  "url": "https://steamcomun1ty.com/id=5944478616"
}

Successful Scan - Benign URL

{
  "detection_method": "ai-model",
  "matched_signatures": 0,
  "probability": 0.13061513415575468,
  "result": "benign",
  "url": "https://google.com"
}

Error Response - Invalid or Unreachable URL

HTTP status: 400 Bad Request or 500 Internal Server Error, depending on the cause.

{
  "error": "Invalid or unreachable URL."
}

Response Fields

detection_method string

Indicates the primary method used to classify the URL.

  • ai-model: classification was primarily based on AI learned patterns.
  • rule-based: classification was made from a direct match with known malicious signatures.
  • hybrid: a combination of AI and rule-based methods contributed significantly.
  • HTML Fetch Failed: the URL could not be reached or HTML content could not be retrieved.
matched_signatures integer

The number of distinct malicious signatures found in the scanned URL's content or structure.

probability float

A value between 0.0 and 1.0 representing model confidence that the URL is malicious.

result string

The final classification of the URL.

  • malicious: highly likely to be phishing, malware, or scam content.
  • benign: deemed safe based on analysis.
  • cannot classify: classification could not be completed.
url string

The original, un-encoded URL submitted for scanning.

Safety

Security Considerations

  • Always use HTTPS when making requests to the LinkShieldAI API.
  • Keep your API key secure and do not expose it publicly.

Example

Code Examples

For this endpoint: https://api.linkshieldai.com/?key={key}&url={url}

import aiohttp
import asyncio

async def check_mal(url, API_key):
    """
    Checks if the specified website is likely malicious.

    Parameters:
        url (str): The URL of the website to check.
        API_key (str): Your API key for LinkShieldAI.

    Returns:
        bool: True if the website might be malicious, False otherwise.
    """
    API_ENDPOINT = f'https://api.linkshieldai.com/?key={API_key}&url={url}'

    async with aiohttp.ClientSession() as session:
        try:
            async with session.get(API_ENDPOINT, timeout=10) as response:
                if response.status == 200:
                    data = await response.json()

                    result = data.get('result', "Failed to connect to the site.")

                    if result == "Might be malicious":
                        return True
                    else:
                        return False
        except asyncio.TimeoutError:
            print("Couldn't connect to the API.")
