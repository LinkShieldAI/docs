Documentation

Build safer apps with LinkShieldAI

LinkShieldAI helps developers scan URLs for phishing, malware, scam pages, NSFW content, and other unsafe destinations before users click them.

Create a free account Use the Developer Portal to manage keys, usage, webhooks, and reports. Install an SDK Use Python, JavaScript, PHP, or Rust clients with typed results, retries, and CLI commands. Call the API directly Scan URLs with simple GET endpoints and JSON responses.

Start here

Quickstart

  1. Create a free developer account Open the Developer Portal signup page, enter your email, and a password with at least 8 characters.
  2. Get your API key Sign in to the portal to view usage, rotate keys, configure webhooks, and report false positives.
  3. Install an SDK Choose Python, JavaScript, PHP, or Rust. Each SDK wraps the same API endpoints and uses the same API key.
  4. Run your first scan Use the SDK, CLI, or direct API endpoint depending on your project.

Choose your SDK

Python pip install linkshieldai==0.2.2 JavaScript / TypeScript npm install linkshieldai PHP composer require linkshieldai/linkshieldai Rust linkshieldai = "0.1"

SDK

Python SDK Setup

The official package is available on PyPI as linkshieldai 0.2.2. It requires Python 3.10 or newer and wraps the LinkShieldAI API at https://api.linkshieldai.com. 

python -m pip install linkshieldai==0.2.2

Option 1: pass the key directly

from linkshieldai import LinkShieldAI

client = LinkShieldAI(api_key="YOUR_API_KEY")
result = client.basic_check("https://example.com")

print(result.result)
print(result.is_malicious)
print(result.raw)

Option 2: use an environment variable

# PowerShell
$env:LINKSHIELDAI_API_KEY = "YOUR_API_KEY"
from linkshieldai import LinkShieldAI

client = LinkShieldAI()
result = client.chimera("https://google.com")

print(result.result)
print(result.raw)

Async client

import asyncio
from linkshieldai import AsyncLinkShieldAI

async def main():
    async with AsyncLinkShieldAI(api_key="YOUR_API_KEY") as client:
        result = await client.chimera("https://google.com")
        print(result.result)
        print(result.raw)

asyncio.run(main())

SDK

Rust SDK Setup

The Rust SDK is an async crate for Rust services, security tools, CLIs, and high-reliability URL scanning pipelines. It uses typed result structs and a single error enum. 

[dependencies]
linkshieldai = "0.1"
tokio = { version = "1", features = ["macros", "rt-multi-thread"] }

Run a basic scan

use linkshieldai::LinkShieldAI;

#[tokio::main]
async fn main() -> linkshieldai::Result<()> {
    let client = LinkShieldAI::new("YOUR_API_KEY")?;
    let result = client.basic_check("https://example.com").await?;

    println!("{:?}", result.result);
    println!("{}", result.is_malicious);

    Ok(())
}

Use an environment variable

# PowerShell
$env:LINKSHIELDAI_API_KEY = "YOUR_API_KEY"
use linkshieldai::LinkShieldAI;

let client = LinkShieldAI::new("")?;
let result = client.chimera("https://google.com").await?;

println!("{:?}", result.result);
println!("{:?}", result.raw);

CLI

Command Line Usage

The Python, JavaScript, PHP, and Rust SDKs include command-line tools. You can pass the API key with --api-key, or omit it when LINKSHIELDAI_API_KEY is set.

Python

linkshieldai --api-key YOUR_API_KEY basic https://example.com
linkshieldai --api-key YOUR_API_KEY detailed https://example.com
linkshieldai --api-key YOUR_API_KEY nsfw https://example.com
linkshieldai --api-key YOUR_API_KEY chimera https://google.com
linkshieldai --api-key YOUR_API_KEY screenshot 05046f.png --output site.png

JavaScript / TypeScript

linkshieldai --api-key YOUR_API_KEY basic https://example.com
linkshieldai --api-key YOUR_API_KEY chimera https://google.com

PHP

vendor/bin/linkshieldai --api-key YOUR_API_KEY basic https://example.com
vendor/bin/linkshieldai --api-key YOUR_API_KEY chimera https://google.com

Rust

cargo run --bin linkshieldai -- --api-key YOUR_API_KEY basic https://example.com
cargo run --bin linkshieldai -- --api-key YOUR_API_KEY chimera https://google.com

Access

Authentication

LinkShieldAI authenticates requests with an API key. For direct API calls, include the key in the key query parameter. For SDKs, pass it to the client or set LINKSHIELDAI_API_KEY. 

GET https://api.linkshieldai.com/chimera?key=YOUR_API_KEY&url=https://google.com

Usage

Rate Limits

1,000 requests per month

Need more requests? Sign in to the Developer Portal to expand your usage.

When you are close to your limit, add retry handling and catch rate-limit errors in your app or bot.

Reference

API Endpoints

Every endpoint below can be called directly over HTTPS. The SDKs wrap the same endpoints and normalize common fields for easier use in code.

Endpoint

Basic Check

GET
URL
https://api.linkshieldai.com/?key={key}&url={url}
Use it for
Fast URL safety checks when you only need a simple safe or suspicious result.
from linkshieldai import LinkShieldAI

client = LinkShieldAI(api_key="YOUR_API_KEY")
result = client.basic_check("https://example.com")

if result.is_malicious:
    print("Block or review this URL")
else:
    print("No malicious signal found")

Example responses

{"result":"likely safe"} {"result":"Might be malicious"} {"result":"The system didn't detect anything malicious."} {"Error":"some error"}

Endpoint

Detailed Check

GET
URL
https://api.linkshieldai.com/classify_link?key={key}&url={url}
Use it for
Getting a safety result, screenshot URL, and detected phishing target or brand tag.
result = client.detailed_check("https://example.com")

print(result.result)
print(result.screenshot_url)
print(result.tag)

SDKs normalize the API field "screenshot url" to the language's usual field style: screenshot_url in Python and Rust, screenshotUrl in JavaScript and PHP.

Example response

{
  "result": "Might be malicious",
  "screenshot url": "https://api.linkshieldai.com/screenshot/1b0745.png",
  "tag": "Yahoo"
}

Successful detailed scans return one of: Likely safe, Might be malicious, or The system didn't detect anything malicious.

Endpoint

Get Website Screenshot

GET
URL
https://api.linkshieldai.com/screenshot/{file_name}
Use it for
Downloading a screenshot file returned by a detailed scan.
image_bytes = client.get_screenshot("05046f.png")
client.get_screenshot("https://api.linkshieldai.com/screenshot/05046f.png", "site.png")

Endpoint

NSFW Check

GET
URL
https://api.linkshieldai.com/nsfw/site?key={key}&url={url}
Use it for
Checking whether a URL is flagged as NSFW or pornographic in the database.
result = client.nsfw_check("https://example.com")
print(result.is_nsfw)
{"result":"False"} {"result":"True"} {"Error":"placeholder error"}

Endpoint

Chimera AI Classification

GET

Chimera is the advanced classification endpoint. It combines reputation data, fingerprint matching, and AI detection to identify malicious URLs. The response exposes only the final classification and scanned URL.

URL
https://api.linkshieldai.com/chimera?key={key}&url={url}
Use it for
Moderation pipelines, Discord bots, browser extensions, and user-facing link checks.
result = client.chimera("https://google.com")

print(result.result)
print(result.raw)

Example request

GET https://api.linkshieldai.com/chimera?key=YOUR_API_KEY&url=https://somethingmalicious.com

Successful responses

{
  "result": "Might be malicious",
  "url": "https://somethingmalicious.com"
}
{
  "result": "likely safe",
  "url": "https://google.com"
}
{
  "result": "UNKNOWN",
  "url": "https://example.com"
}

A result of UNKNOWN means Chimera did not find enough evidence to classify the URL, including when PhishPrint identifies suspicious but unconfirmed similarity. It is not a guarantee that the URL is safe.

Response fields

result string

Final classification: likely safe, Might be malicious, or UNKNOWN.

url string

The normalized URL scanned by Chimera.

Error responses

Status Response
400 {"error":"Missing \"key\" or \"url\" parameter."}
400 {"error":"Invalid or unreachable URL."}
429 {"error":"API key rate limit exceeded."}
502 {"error":"Unable to scan URL."}
500 {"error":"Internal server error."}

Handling

Errors

SDKs preserve raw API payloads on result objects through raw and expose clear error types for common failure modes. 

from linkshieldai import (
    APIConnectionError,
    APIResponseError,
    APIStatusError,
    AuthenticationError,
    RateLimitError,
)
AuthenticationError

Raised when the API key is missing.

RateLimitError

Raised for HTTP 429 responses.

APIStatusError

Raised for non-success HTTP status responses.

APIResponseError

Raised for malformed JSON or API payloads containing Error or error.

APIConnectionError

Raised for timeouts, DNS failures, or connection failures.

Production

Security Notes

  • Always call the API over HTTPS.
  • Keep API keys server-side. Do not expose them in browser JavaScript.
  • Use retries for temporary failures. The SDK retries connection failures and HTTP 429, 502, 503, and 504 by default.
  • Catch RateLimitError when running moderation bots, browser extension backends, or high-volume pipelines.
