Documentation

Build safer apps with LinkShieldAI

LinkShieldAI helps developers scan URLs for phishing, malware, scam pages, NSFW content, and other unsafe destinations before users click them.

Create a free account Use the Developer Portal to manage keys, usage, webhooks, and reports. Install the Python SDK Use sync clients, async clients, typed result objects, retries, and CLI commands. Call the API directly Scan URLs with simple GET endpoints and JSON responses.

Start here

Quickstart

  1. Create a free developer account Open the Developer Portal signup page, enter your name, email, and a password with at least 8 characters.
  2. Get your API key Sign in to the portal to view usage, rotate keys, configure webhooks, and report false positives.
  3. Install the SDK Use pip install linkshieldai==0.2.2 with Python 3.10 or newer.
  4. Run your first scan Use the SDK, CLI, or direct API endpoint depending on your project.

Account

Create a Free Developer Account

The Developer Portal is where you manage API access. Use it to sign in, create a free account, view usage, rotate keys, configure webhooks, and report false positives.

Signup URL https://developer.linkshieldai.com/portal.php?signup=1

Required signup fields

  • Name
  • Email address
  • Password with at least 8 characters

After creating the account, return to the portal and sign in with your email and password.

SDK

Python SDK Setup

The official package is available on PyPI as linkshieldai 0.2.2. It requires Python 3.10 or newer and wraps the LinkShieldAI API at https://api.linkshieldai.com. 

python -m pip install linkshieldai==0.2.2

Option 1: pass the key directly

from linkshieldai import LinkShieldAI

client = LinkShieldAI(api_key="YOUR_API_KEY")
result = client.basic_check("https://example.com")

print(result.result)
print(result.is_malicious)
print(result.raw)

Option 2: use an environment variable

# PowerShell
$env:LINKSHIELDAI_API_KEY = "YOUR_API_KEY"
from linkshieldai import LinkShieldAI

client = LinkShieldAI()
result = client.chimera("https://google.com")

print(result.result)
print(result.probability)
print(result.detection_method)
print(result.matched_signatures)

Async client

import asyncio
from linkshieldai import AsyncLinkShieldAI

async def main():
    async with AsyncLinkShieldAI(api_key="YOUR_API_KEY") as client:
        result = await client.chimera("https://google.com")
        print(result.result, result.probability)

asyncio.run(main())

CLI

Command Line Usage

Installing the Python package also gives you a small command-line tool. You can pass the API key with --api-key, or omit it when LINKSHIELDAI_API_KEY is set. 

linkshieldai --api-key YOUR_API_KEY basic https://example.com
linkshieldai --api-key YOUR_API_KEY detailed https://example.com
linkshieldai --api-key YOUR_API_KEY nsfw https://example.com
linkshieldai --api-key YOUR_API_KEY chimera https://google.com
linkshieldai --api-key YOUR_API_KEY screenshot 05046f.png --output site.png

Access

Authentication

LinkShieldAI authenticates requests with an API key. For direct API calls, include the key in the key query parameter. For the Python SDK, pass it to the client or set LINKSHIELDAI_API_KEY. 

GET https://api.linkshieldai.com/chimera?key=YOUR_API_KEY&url=https://google.com

Usage

Rate Limits

1,000 requests per month

Need more requests? Sign in to the Developer Portal to expand your usage.

When you are close to your limit, add retry handling and catch rate-limit errors in your app or bot.

Reference

API Endpoints

Every endpoint below can be called directly over HTTPS. The Python SDK wraps the same endpoints and normalizes common fields for easier use in code.

Endpoint

Basic Check

GET
URL
https://api.linkshieldai.com/?key={key}&url={url}
Use it for
Fast URL safety checks when you only need a simple safe or suspicious result.
from linkshieldai import LinkShieldAI

client = LinkShieldAI(api_key="YOUR_API_KEY")
result = client.basic_check("https://example.com")

if result.is_malicious:
    print("Block or review this URL")
else:
    print("No malicious signal found")

Example responses

{"result":"likely safe"} {"result":"Might be malicious"} {"result":"The system didn't detect anything malicious."} {"Error":"some error"}

Endpoint

Detailed Check

GET
URL
https://api.linkshieldai.com/classify_link?key={key}&url={url}
Use it for
Getting a safety result, screenshot URL, and detected phishing target or brand tag.
result = client.detailed_check("https://example.com")

print(result.result)
print(result.screenshot_url)
print(result.tag)

The SDK normalizes the API field "screenshot url" to screenshot_url.

Example response

{
  "result": "Might be malicious",
  "screenshot url": "https://api.linkshieldai.com/screenshot/1b0745.png",
  "tag": "Yahoo"
}

Endpoint

Get Website Screenshot

GET
URL
https://api.linkshieldai.com/screenshot/{file_name}
Use it for
Downloading a screenshot file returned by a detailed scan.
image_bytes = client.get_screenshot("05046f.png")
client.get_screenshot("https://api.linkshieldai.com/screenshot/05046f.png", "site.png")

URL

Checking whether a URL is flagged as NSFW or pornographic in the database.
result = client.nsfw_check("https://example.com")
print(result.is_nsfw)

Endpoint

Chimera AI Classification

GET

Chimera is the advanced classification endpoint. It uses AI and signature detection to identify phishing, malware, scams, and other malicious URL patterns.

URL
https://api.linkshieldai.com/chimera?key={key}&url={url}
Use it for
Risk scoring, moderation pipelines, Discord bots, browser extensions, and user-facing link checks.
result = client.chimera("https://google.com")

print(result.result)
print(result.probability)
print(result.detection_method)
print(result.matched_signatures)

Example request

GET https://api.linkshieldai.com/chimera?key=YOUR_API_KEY&url=https://steamcomun1ty.com/id=5944478616

Example response

{
  "detection_method": "ai-model",
  "matched_signatures": 0,
  "probability": 0.9947241392537983,
  "result": "malicious",
  "url": "https://steamcomun1ty.com/id=5944478616"
}

Response fields

detection_method string

Primary classification method, such as ai-model, rule-based, or hybrid.

matched_signatures integer

Number of malicious signatures found in the scanned URL's content or structure.

probability float

Model confidence between 0.0 and 1.0 that the URL is malicious.

result string

Final classification, commonly malicious, benign, or cannot classify.

url string

The original URL submitted for scanning.

Handling

Errors

The SDK preserves raw API payloads on result objects through .raw and exposes clear exception types for common failure modes. 

from linkshieldai import (
    APIConnectionError,
    APIResponseError,
    APIStatusError,
    AuthenticationError,
    RateLimitError,
)
AuthenticationError

Raised when the API key is missing.

RateLimitError

Raised for HTTP 429 responses.

APIStatusError

Raised for non-success HTTP status responses.

APIResponseError

Raised for malformed JSON or API payloads containing Error or error.

APIConnectionError

Raised for timeouts, DNS failures, or connection failures.

Production

Security Notes

  • Always call the API over HTTPS.
  • Keep API keys server-side. Do not expose them in browser JavaScript.
  • Use retries for temporary failures. The SDK retries connection failures and HTTP 429, 502, 503, and 504 by default.
  • Catch RateLimitError when running moderation bots, browser extension backends, or high-volume pipelines.
